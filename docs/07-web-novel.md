# 07. 웹소설과 작품 크레딧

웹툰과 같은 스튜디오에서 웹소설을 만들고, 모든 작품(웹툰·웹소설)에 제작 이력과 크레딧을 남기는 규칙이에요.
기획서: "NORIVA 웹소설 서비스 기획" (Claude 문서). 2026-11-25 대표 승인(추천안).

## 1. 확정한 정책

| 항목 | 정한 값 |
| --- | --- |
| 무료 회차 | 처음 10화 |
| 언어 | 한국어 먼저. 영어는 3단계 |
| 시작 규모 | 3작품, 작품당 주 5회(월~금). 1개는 기존 웹툰 세계관 |
| 한 회 분량 | 공백 포함 5,000~5,500자. 4,500자 미만이나 6,500자 초과면 다시 고쳐 씀 |
| 출시 분량 | 작품당 25화 공개 + 20화 비축 |
| 가격 | 유료 회차 1코인(100원), 먼저 보기 2코인. 패스·기다무(24시간)는 웹툰과 같음 |
| 기다무 제외 | 작품별로 정함. 매일 연재 웹소설은 최신 10화 |
| 연령 등급 | 전체, 12세, 15세만. 19세 작품은 만들지 않음 |

## 2. 금지 소재 (모든 작품)

아래 소재는 집필 지침, 퇴고 검사, 대표 검수에서 세 번 걸러요. 걸리면 공개할 수 없어요.

1. 노골적인 성적 묘사, 성범죄 미화, 미성년자를 성적으로 그리는 내용, 근친
2. 마약·자살·범죄 방법을 따라 할 수 있게 쓰거나 미화하는 내용
3. 특정 집단에 대한 혐오와 차별
4. 실존 인물·단체를 깎아내리는 내용
5. 역사 왜곡, 일제 강점기 미화
6. 특정 작품의 표절이나 모방
7. 불법 도박 홍보

## 3. 제작 흐름

웹소설은 작품을 만들 때 형식을 '웹소설'로 고르면 아래 단계로 가요.

- 작품 단계: ① 장르·소재 → ② 스토리 → ③ 인물 → ③+ 고증 자료
- 회차 단계: ⑤ 회차 플롯 → ⑥ 집필 → ⑦ 퇴고·교정 (대표가 승인하면 검수 끝)

웹툰의 ④ 화풍, ④+ 인물 시트, ⑥ 콘티, ⑦ 작화, ⑧ 말풍선, ⑨ 검수는 쓰지 않아요.
① ② ③ ⑤ 단계는 웹소설일 때 '웹소설 작가' 지침을 함께 읽어서 컷·말풍선 대신 문장과 장면으로 써요.

| 단계 | 하는 일 |
| --- | --- |
| ⑥ 집필 | 승인한 회차 플롯과 지난 회 끝부분을 읽고 본문을 써요. 지침 점검 뒤, 분량이 기준을 벗어나면 한 번 고쳐 써요 |
| ⑦ 퇴고·교정 | 맞춤법, 문체, 분량, 반복 표현, 설정 충돌, 금지 소재를 검사하고 고친 본문과 고친 곳 목록을 만들어요. 대표는 고친 곳만 색으로 보고 승인해요 |

## 4. 제작 이력과 크레딧 (웹툰·웹소설 공통)

### 왜 필요한가
- 성명표시권(저작권법 제12조): 사람 저작자는 이름 표시를 요구할 수 있고, 이 권리는 넘길 수 없어요(제14조).
- 원작(제5조, 제22조): 남의 작품을 각색하려면 허락이 필요하고 원작을 밝혀야 해요.
- AI 생성물: AI가 만든 부분은 보호받기 어려워요. AI를 작가로 올리지 않고, 대표의 기획·선택·수정 기록(제작 원장)을 남겨요.
- AI 제작 표시: 의무 대상인지 해석이 갈리지만 모든 작품에 표시해요.

### 항목

| 역할 | 구분 | 기본값 |
| --- | --- | --- |
| 글 | 필수 | NORIVA 스튜디오 |
| 그림 | 필수 (웹툰) | NORIVA 스튜디오 |
| 저작권자 | 필수 | 주식회사 제이엠비코퍼레이션 |
| AI 제작 표시 | 필수 | AI 협업 제작 (글: Claude, 그림: 이미지 생성 AI) |
| 원작 | 있을 때 필수 + 이용 근거(계약·저작권 만료·자체 원작) | 없음 |
| 사람 참여자 | 있을 때 필수 | 없음 |
| 화풍, 각색, 콘티, 채색, 식자, 표지, 교정, 고증·참고 자료, 번역, 직접 입력 | 선택 | 없음 |

- 작품을 만들면 필수 항목이 기본값으로 들어가요. 제작 중 언제든 '크레딧' 화면에서 더하고 고칠 수 있어요.
- 더하고 고치고 지운 기록은 모두 제작 원장에 남아요.
- 공개 전에 검사해요. 필수 항목이 비었거나, 원작이 있는데 이용 근거가 없으면 공개할 수 없어요.
- '제작 이력' 화면은 단계별로 어떤 AI 모델이 만들고 대표가 언제 승인·수정했는지 보여 주고, 파일로 내려받을 수 있어요.

법적 내용은 일반 안내예요. 외주 계약이나 남의 작품 각색은 변호사 확인을 받아요.
