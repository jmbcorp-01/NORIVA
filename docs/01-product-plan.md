# 01. 제품 기획서

## 1. 서비스 정의

**NORIVA**는 한국의 역사, 설화, 민속을 뿌리로 한 웹툰만 연재하는 플랫폼이에요. 작품은 대표 한 명이 AI 에이전트를 지휘해서 만들고, 모든 회차는 대표의 승인을 거쳐 공개돼요.

- **한 줄 소개:** "한국의 옛이야기가 지금의 웹툰이 되는 곳"
- **차별점:**
  - 장르는 다양하되 뿌리는 모두 한국 (도깨비, 구미호, 저승, 무속, 조선 궁중, 삼국 전쟁, 근대 경성 등)
  - 회차마다 짧은 "뿌리 노트"(이 이야기의 원전 설화나 역사 한 줄)를 붙여서 콘텐츠의 깊이를 보여줌
  - 1인 운영이라 작가 수익 배분이 없어서, 구독형 "전 회차 무제한"을 낮은 가격에 제공할 수 있음

### 대상 독자

| 구분 | 설명 | 언어 |
| --- | --- | --- |
| 1차 | 한국 웹툰을 즐겨 보는 20~30대, 오컬트·사극·판타지 선호 | 한국어 |
| 2차 | 해외의 K-콘텐츠 팬 (이전 1화 시험은 미국 독자를 겨냥해 영어로 제작) | 영어 |

말풍선 글자는 그림과 분리된 데이터로 저장하므로 같은 그림에 한국어와 영어를 모두 얹을 수 있어요. 어느 시장을 먼저 열지는 결제 수단이 달라지기 때문에 대표가 정해야 해요 (아래 5절).

## 2. 서비스 구성

```
┌──────────────────────┐   ┌───────────────────────────┐
│ 독자 앱 (웹 + 앱)     │   │ 관리자 스튜디오 (대표 전용) │
│ 탐색·뷰어·결제·구독   │   │ 지침·소재·제작·검수·운영    │
└──────────┬───────────┘   └─────────────┬─────────────┘
           │                             │
           ▼                             ▼
     ┌──────────────────────────────────────────┐
     │ API + DB (회원, 작품, 회차, 결제, 지침)    │
     └──────────────────────┬───────────────────┘
                            ▼
     ┌──────────────────────────────────────────┐
     │ 에이전트 파이프라인 (작업 큐 + 제작 서버)  │
     │ LLM(Claude) · 이미지 모델 · 품질검사       │
     └──────────────────────────────────────────┘
```

## 3. 독자 앱

### 3.1 화면과 기능

| 화면 | 기능 |
| --- | --- |
| 홈 | 오늘의 연재(요일별), 신작, 인기, 완결, "이어보기" |
| 탐색 | 장르별, 뿌리별(설화·역사 시대·민속 신앙), 요일별, 키워드 검색 |
| 작품 상세 | 표지, 소개, 뿌리 노트, 회차 목록(무료/기다무/유료/선공개 표시), 관심 등록 |
| 뷰어 | 세로 스크롤, 다음 화 자동 이어보기, 회차 끝 "다음 화 미리보기" 카드, 댓글, 좋아요, 언어 전환 |
| 결제 | 코인 충전, 회차 구매 확인, 구독 가입·해지 |
| 내 서재 | 관심 작품, 최근 본 작품, 구매한 회차, 기다무 충전 상태 |
| 내 정보 | 계정, 구독 상태, 코인 내역, 알림 설정, 성인 인증 |

### 3.2 회원

- 가입: 카카오, 네이버, 구글, 애플 간편 로그인 (이메일 가입은 보조)
- 성인 작품을 열 때만 본인인증 (PASS 등)
- 만 14세 미만은 가입 제한, 미성년자 결제는 한도와 법정대리인 동의 규정 적용

## 4. 멤버십과 과금

한국 웹툰 시장에서 검증된 세 가지 방식을 섞어요. 처음에는 단순하게 시작하고, 지표를 보며 조정해요.

### 4.1 회차 상태

| 상태 | 누가 볼 수 있나 |
| --- | --- |
| 무료 | 누구나 (작품마다 1~3화 이상, 첫 3화는 반드시 무료) |
| 기다리면 무료 | 작품마다 24시간에 1화씩 무료로 열림. 최신 3화는 제외 |
| 유료 | 코인으로 소장, 또는 구독자는 무제한 열람 |
| 선공개 | 정식 공개 전 1~3화. 코인으로만 열람 (구독자는 할인) |

### 4.2 코인

- 1코인 = 100원. 회차 1화 = 3코인 (300원), 선공개 1화 = 5코인
- 충전 묶음: 10코인 1,000원 / 50+5 보너스 5,000원 / 100+15 보너스 10,000원 / 300+60 보너스 30,000원
- 구매 회차는 영구 소장. 결제로 충전한 유상 코인과 이벤트로 받은 무상 코인을 나눠 기록하고, 무상 코인을 먼저 써요
- 미사용 유상 코인은 환불 규정에 따라 환불 (전자상거래법, 콘텐츠이용자보호지침)

### 4.3 구독 (NORIVA 패스)

| 등급 | 월 가격(안) | 혜택 |
| --- | --- | --- |
| 무료 회원 | 0원 | 무료 회차, 기다무, 광고 노출 |
| 패스 | 6,900원 | 공개된 모든 회차 무제한, 광고 없음, 기다무 대기 없음, 매월 선공개용 10코인 |
| 패스 연간 | 69,000원 | 패스와 동일, 2개월 무료 효과 |

작가 수익 배분이 없으니 "무제한 열람" 구독이 가능하고, 이게 대형 플랫폼과 다른 강점이에요. 선공개만 코인으로 남겨서 코인 매출도 유지해요.

### 4.4 결제 수단

| 시장 | 권장 | 메모 |
| --- | --- | --- |
| 국내 | 토스페이먼츠 (카드, 간편결제, 빌링키 자동결제) | 사업자 등록, 통신판매업 신고, PG 심사가 필요해요. 대표가 직접 해야 하는 일이에요 |
| 해외 | Paddle 또는 Lemon Squeezy 같은 판매대행(MoR) | Stripe는 한국 법인을 받지 않아요. 판매대행은 해외 세금 처리까지 대신해 줘요. 한국 사업자 가입 가능 여부는 가입 전에 확인해야 해요 |
| 앱 | 처음에는 웹(PWA) 결제만 | 앱스토어 인앱결제는 수수료가 15~30%라서, 앱은 2단계에 내고 결제는 웹으로 안내하는 방식을 검토 |

## 5. 대표가 정할 것

1. **첫 시장:** 국내(한국어, 토스) 먼저인지, 해외(영어, 판매대행) 먼저인지. 기획서는 한국어 우선으로 썼고, 영어는 같은 그림에 말풍선만 바꿔 동시에 낼 수 있게 설계했어요.
2. **가격:** 회차 300원, 패스 6,900원은 시작안이에요.
3. **첫 오픈 작품 수:** 3개 작품 × 10화 비축을 권장해요 (아래 8절).

## 6. 관리자 스튜디오 (대표 전용)

대표가 하는 일은 "지시하고, 고르고, 승인하는 것"이에요. 에이전트가 할 수 있는 모든 작업을 여기서 시킬 수 있어요.

| 메뉴 | 기능 |
| --- | --- |
| 대시보드 | 오늘 매출, 신규 가입, 구독자 수, 회차별 조회·이탈 지점, 제작 비용, 대기 중인 승인 |
| 소재 라이브러리 | 설화·역사 인물·사건·민속 신앙·장소 항목 관리, 원전과 고증 메모, 사용 이력 |
| 지침 관리 | 전체·장르별·작품별 지침, 에이전트별 프롬프트, 금지 목록, 버전 관리, 이전 버전 되돌리기 |
| 작화 지침 | 작품별 화풍 카드, 팔레트, 캐릭터 시트, 금지 요소, 사용할 이미지 모델, 참고 이미지 |
| 작품 기획 | 장르·소재 선택 → 기획안 여러 개 생성 → 골라서 수정 → 작품 설정집 확정 |
| 제작 보드 | 회차별 파이프라인 진행 상태(칸반), 단계별 결과 보기, 다시 생성, 직접 수정, 승인 |
| 컷 편집기 | 컷 단위로 다시 그리기(부분 수정 포함), 말풍선 위치·글꼴·효과음 수정, 세로 배치 미리보기 |
| 검수 | 자동 품질 점수와 결함 목록, 독자 화면 미리보기, 최종 승인 |
| 연재 관리 | 공개 예약, 회차 상태(무료/기다무/유료/선공개) 전환 일정, 휴재 공지 |
| 회원·결제 | 회원 검색, 구독·코인 내역, 환불 처리, 쿠폰과 이벤트 코인 |
| 비용 | 작품·회차·단계별 API 비용, 월 예산과 경고 |

## 7. 운영 지표

| 지표 | 목표(초기) | 왜 보나 |
| --- | --- | --- |
| 1화 → 3화 도달률 | 40% 이상 | 첫 3화 훅이 먹히는지 |
| 회차 완독률 | 70% 이상 | 컷 호흡과 전개 |
| 다음 화 즉시 이동률 | 50% 이상 | 절단신공이 통하는지 |
| 무료 → 결제 전환율 | 3~5% | 과금 설계 |
| 패스 월 해지율 | 10% 이하 | 연재 주기와 만족도 |
| 회차당 제작비 | 1만 원 이하 | 1인 운영 수익성 (1화 시험은 약 2만 원) |

뷰어는 스크롤 깊이를 컷 단위로 기록해서, 독자가 어느 컷에서 많이 떠나는지 관리자 대시보드에 보여줘요. 이 데이터는 다음 화 콘티 지침에 다시 반영돼요.

## 8. 연재 운영

- 한국 웹툰 관행대로 **연재 시작 전 10화 비축**, 주 1~2회 연재
- 시즌제: 시즌당 30~50화, 시즌 사이 휴재
- 회차 분량: 50~70컷 (스마트폰 세로 스크롤 기준 약 3~5분)
- 휴재와 지연은 공지 템플릿으로 바로 알림

## 9. 법무와 준비물 (대표가 직접)

| 항목 | 내용 |
| --- | --- |
| 사업자 등록 | 개인사업자 (업종: 전자책·디지털 콘텐츠 판매, 소프트웨어 개발 등) |
| 통신판매업 신고 | 온라인 판매에 필수 |
| 부가통신사업 신고 | 웹 서비스 운영 시 해당 여부 확인 |
| PG 심사 | 토스페이먼츠 가입, 사이트에 약관·환불 규정·사업자 정보 표시 필요 |
| 약관과 개인정보 처리방침 | 이용약관, 유료 서비스 약관, 개인정보 처리방침, 청소년 보호 정책 |
| AI 생성물 표시 | 인공지능 기본법(2026년 1월 22일 시행)은 생성형 AI 서비스 제공자에게 결과물 표시 의무를 둬요. 생성 도구를 쓰는 웹툰 제작사는 제공자가 아니라 대상이 아니라는 해석([코리아타임스](https://www.koreatimes.co.kr/business/tech-science/20260129/unclear-guidance-vague-terms-in-ai-basic-act-leave-businesses-in-limbo))도 있지만 공식 판단은 아니에요. 과기정통부 투명성 가이드라인을 확인하고, 그와 별개로 작품 상세에 "AI 협업 제작" 표기를 기본으로 해요 |
| 저작권 | AI 생성물 자체는 저작권 보호가 어렵다는 게 현재 해석이에요. 대표의 선택·수정·편집 기록(제작 원장)을 남겨 사람의 창작 기여를 입증할 자료로 써요 |
| 연령 등급 | 웹툰 자율규제 기준에 맞춰 작품별 전체/12/15/18세 표시 |

법무 항목은 일반적인 안내예요. 결제 오픈 전에 세무사나 변호사에게 한 번 확인받는 걸 권해요.
