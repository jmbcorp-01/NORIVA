# 04. 작화·품질 지침 (AI처럼 보이지 않게)

목표는 하나예요. **독자가 "AI 그림이네"라고 느끼지 않는 것.** 이를 위해 "AI스러움"을 구체적인 결함 목록으로 바꾸고, 생성 전(지시와 참조), 생성 중(모델과 제어), 생성 후(검사와 후처리) 세 단계에서 막아요.

1화 시험(Salt & Incense)에서 나온 문제와 이 지침의 대응이에요.

| 1화 시험의 문제 | 대응 |
| --- | --- |
| 전체적으로 AI 그림처럼 보임 | 2장 AI 티 목록, 5장 후처리, 6장 채점표 |
| 일본식 도리이가 계속 그려짐 | 3장 한국 고증 금지 목록, 자동 검출 |
| 부적·간판에 가짜 글자 | 그림 속 글자는 생성하지 않고 후처리로 넣음 (5.3) |
| 반사에만 보여야 할 여우 꼬리가 밖에도 보임 | 콘티의 "보이면 안 되는 것" 필드, 검수 항목 |
| 화면 밖 화자가 그려짐 | 콘티에서 "화면 밖 화자"를 명시하고 프롬프트에서 제외 |
| 캐릭터 시트가 자기 화풍을 강요 | 화풍 확정 후 시트 재작성 (03번 ④) |
| 품질검수 점수가 수렴하지 않음 | 고정 채점표, 최대 2라운드 (6장) |

## 1. 한국 웹툰 화풍의 기본

작품마다 고유 화풍을 정하되(특정 작가 모방 금지), 한국 세로 웹툰이 공통으로 가진 특징은 지켜요.

**A-1. 선.** 깔끔하고 자신 있는 외곽선, 인물은 배경보다 굵은 선. 선 굵기에 강약(입체감 쪽이 굵고, 빛 받는 쪽이 가늚). 선이 없는 페인팅풍은 작품이 그 화풍을 고른 경우에만.

**A-2. 채색.** 기본은 셀 채색(밑색 + 그림자 1~2단계 + 하이라이트). 피부는 과하게 매끈하지 않게, 볼과 코끝에 옅은 홍조. 그라데이션은 배경과 분위기 연출에만.

**A-3. 장면별 색 온도.** 장면마다 지배색을 하나 정해요 (공포: 청록·남색, 회상: 바랜 세피아, 감정 고조: 주황·붉은색). 화풍 카드에 장면 종류별 팔레트를 둬요.

**A-4. 배경.** 인물 중심 컷은 배경을 단순화하거나 흐리게, 장소 소개 컷(establishing)은 공들인 배경. 대화가 긴 구간은 배경 없이 색면이나 효과선으로 처리해서 시선을 얼굴에 모아요. 모든 컷에 화려한 배경을 넣는 것 자체가 AI의 특징이에요.

**A-5. 연출 기호.** 땀방울, 혈관 표시, 집중선, 배경 꽃·반짝이, 어두운 사선 등 웹툰 기호를 감정 표현에 써요.

**A-6. 비율.** 성인 인물은 7~8등신 기준, 개그 컷은 SD(2~3등신) 허용. 얼굴은 작품마다 정한 눈 크기와 턱선을 고정.

## 3. 캐릭터 일관성

한 가지 방법으로는 부족해서 여러 겹으로 묶어요. 실제 제작자들도 얼굴은 참조 이미지(IP-Adapter 계열), 체형과 화풍은 캐릭터 LoRA, 자세는 포즈 제어(ControlNet OpenPose)로 나눠 맡기는 조합을 가장 많이 써요.

| 층 | 방법 | 언제 |
| --- | --- | --- |
| 1. 명세 | 캐릭터 시트의 고정 문구(외모, 의상, 소품)를 모든 컷 프롬프트에 그대로 삽입 | 항상 |
| 2. 참조 이미지 | 시트 이미지를 참조로 넣는 편집형 모델 (1화 시험의 nano-banana 방식, seedream4의 다중 참조) | 항상. 컷에 나오는 인물 시트만 넣음 |
| 3. 캐릭터 LoRA | 주인공과 주요 조연은 시트와 승인된 컷 15~30장으로 LoRA 학습 | 작품이 5화 이상 연재로 확정되면 |
| 4. 화풍 LoRA | 승인된 컷으로 작품 화풍 LoRA 학습 | 10화 비축 시점에 |
| 5. 포즈·구도 제어 | 콘티를 간단한 구도 스케치나 포즈 뼈대로 만들어 제어 입력으로 사용 | 액션, 여러 인물 컷 |
| 6. 검사 | 얼굴 임베딩 유사도로 시트와 비교, 기준 미달이면 재생성 | 항상 |

**C-1. 고정 소품 규칙.** 인물마다 "항상 있어야 하는 것"을 둬요 (하나: 왼쪽 손목 붉은 실, 준: 나무 염주). 검수 에이전트가 컷마다 확인해요.

**C-2. 의상 변경은 설정집에 기록.** 회차마다 입는 옷을 장면 단위로 지정해서, 같은 장면 안에서 옷이 바뀌지 않게 해요.

**C-3. 시트 갱신.** 화풍을 바꾸거나 LoRA를 새로 학습하면 시트도 새 버전으로 만들고, 이전 회차와 나란히 놓고 비교해요.

## 4. 모델 선택 원칙

모델은 빨리 바뀌므로 지침은 "역할"로 정하고, 실제 모델은 관리자에서 바꿔요.

| 역할 | 요구 사항 | 시험 후보 |
| --- | --- | --- |
| 캐릭터 컷 | 다중 참조 이미지, 화풍 유지 | nano-banana 계열, seedream4, flux 계열 + LoRA |
| 배경·장소 컷 | 원근과 디테일 | flux 계열 고해상도 |
| 부분 수정 | 손·얼굴·소품만 고치기 | 편집형(인페인팅) 모델 |
| 화풍 LoRA | 학습 가능 | flux 계열 LoRA 학습 |

새 모델은 **고정 시험 세트**(대표 컷 10개: 얼굴 클로즈업, 손 쥐기, 2인 대화, 액션, 실내 배경, 한옥, 무속 소품, 밤 장면, 회상, 군중)로 돌려 6장 채점표 점수와 컷당 비용을 비교한 뒤 채택해요.

## 5. 후처리 (사람 손 느낌 더하기)

생성 직후 그림을 그대로 쓰지 않아요. 아래 처리를 자동으로 거친 뒤 검수로 가요.

**5.1 선 정리.** 선화를 추출해 굵기를 화풍 카드 기준으로 맞추고, 흐린 선을 또렷하게. 선과 채색을 분리해 두면 나중에 색만 고칠 수 있어요.

**5.2 팔레트 맞춤.** 컷의 색을 장면 팔레트로 끌어당겨요 (색 양자화 후 팔레트 매핑, 강도 조절). 같은 장면의 컷끼리 색이 맞춰져요.

**5.3 글자는 그림 밖에서.** 간판, 부적, 편지, 휴대폰 화면 글자는 그림에서 비워 두게 하고(빈 간판, 빈 종이), 실제 한글을 글꼴로 얹어요. 손글씨 편지는 손글씨 글꼴로.

**5.4 질감.** 화풍 카드의 질감(한지, 종이결, 약한 노이즈)을 아주 옅게 덮어서 디지털 매끈함을 줄여요.

**5.5 효과와 기호.** 집중선, 속도선, 땀방울, 효과음은 생성하지 않고 레이어 소스(직접 만든 브러시·스탬프 모음)로 얹어요. 작품마다 같은 소스를 써서 "손맛"이 일관돼요.

**5.6 컷 테두리와 여백.** 모델이 그린 테두리와 레터박스는 잘라내고(1화 시험의 trim_border), 컷 테두리는 화풍 카드 규칙으로 다시 그려요. 일부 컷은 테두리 없이 여백으로 흘려요.

**5.7 장기 목표: 수작업 편집 계층.** 대표나 외주 어시스턴트가 핵심 컷(1화 첫 컷, 절단 컷, 표지)만 직접 손보는 단계를 두면 품질이 크게 올라가요. 컷 편집기에서 레이어 PSD로 내보내기·다시 가져오기를 지원해요.

## 6. 자동 검사와 채점

### 6.1 컷 단위 결함 검사 (자동, 생성 직후)

| 검사 | 방법 | 실패 시 |
| --- | --- | --- |
| 손 | 손 키포인트 검출로 손가락 수와 관절 각도 확인 + 이미지 이해 모델의 2차 확인 | 손 부분 수정 |
| 글자 | 문자 인식(OCR)으로 그림 안 글자 검출. 의도한 글자 영역 외에는 실패 | 해당 영역 지우고 재생성 |
| 얼굴 일관성 | 얼굴 임베딩을 시트와 비교, 기준값 이하면 실패 | 참조 강화 후 재생성 |
| 인물 수 | 사람 검출 수 = 콘티 등장인물 수 | 재생성 |
| 고증 | 이미지 이해 모델에 금지 목록 체크리스트 질문 | 재생성 |
| 고정 소품 | 인물별 필수 소품 유무 질문 | 부분 수정 |
| 화풍 | 화풍 참조 이미지와의 스타일 유사도 | 재생성 |
| 해상도·여백 | 폭 기준(예: 800~1080px), 테두리 검출 | 자동 자르기 |

후보를 2~4장 만들고 결함이 가장 적고 점수가 높은 것을 고르는 방식이 한 장을 여러 번 고치는 것보다 대체로 싸고 빨라요.

### 6.2 회차 채점표 (고정, 100점)

채점표는 회차마다 바꾸지 않고, 바꿀 때는 버전을 올려요. 항목마다 근거 컷 번호와 규칙 코드를 적게 해요.

| 항목 | 배점 | 보는 것 |
| --- | --- | --- |
| 훅과 절단 | 15 | S-1, S-2, S-3 |
| 전개 리듬 | 10 | S-4, S-6, S-12, S-13 |
| 대사 자연스러움 | 15 | D-1~D-7, 금지 표현 수 |
| 캐릭터 일관성 | 15 | 얼굴 유사도 평균, 고정 소품 |
| AI 티 없음 | 20 | 2장 목록, 결함 수 |
| 한국 고증 | 10 | 4.1 목록, 뿌리 노트 |
| 레터링 가독성 | 10 | 말풍선 위치, 읽는 순서, 효과음 |
| 화풍 통일 | 5 | 팔레트, 선 굵기 |

- **합격 기준:** 80점 이상이면서 "AI 티 없음" 16점 이상, 결함 "치명"이 0개
- **수정 라운드:** 최대 2번. 2번 뒤에도 미달이면 점수와 남은 결함 목록을 붙여 대표에게 넘기고, 대표가 승인·반려를 정해요 (1화 시험의 `--accept-qa` 방식)
- **점수 흔들림 방지:** 같은 회차를 같은 채점표로 두 번 채점해서 차이가 5점 넘으면 세 번째 채점의 중앙값을 써요

### 6.3 사람 눈 검수 (대표)

자동 점수가 좋아도 대표는 독자 화면 그대로 한 번 넘겨 봐요. 이때 보는 질문은 세 가지예요.
1. 스크롤을 멈추고 싶은 컷이 있었나 (있으면 좋은 것)
2. "AI 같다"는 느낌이 든 컷이 있었나 (컷 번호 표시 → 재생성)
3. 다음 화를 누르고 싶은가

대표가 표시한 AI 티 컷은 사례 모음에 쌓여서, 검수 에이전트의 예시로 다시 쓰여요. 시간이 지날수록 검수가 대표의 눈에 가까워져요.

## 7. 레터링 품질

- 한글 글꼴: 대사용(가독성 좋은 웹툰용 고딕), 내레이션용(명조 계열), 효과음용(손글씨 계열 여러 개). 상업적 이용이 허용된 글꼴만 사용
- 말풍선은 얼굴, 손, 핵심 소품을 가리지 않음
- 말풍선 꼬리는 말하는 인물의 입 방향, 화면 밖 화자는 꼬리를 컷 가장자리로
- 한 컷에 말풍선 3개 이하
- 효과음은 동작의 방향을 따라 기울이고, 크기로 소리 세기를 표현
