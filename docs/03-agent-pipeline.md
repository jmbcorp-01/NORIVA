# 03. 에이전트 파이프라인

작품 하나가 기획부터 연재까지 가는 단계, 각 단계를 맡는 에이전트, 대표가 승인하는 지점, 앞 단계를 고쳤을 때 뒤 단계를 다시 만드는 규칙이에요.

## 1. 전체 흐름

```
[작품 단위]                                   [회차 단위]
① 장르·소재 ─▶ ② 스토리 ─▶ ③ 인물 ─▶ ④ 화풍 ─┬─▶ ⑤ 회차 플롯 ─▶ ⑥ 콘티 ─▶ ⑦ 작화 ─▶ ⑧ 말풍선 ─▶ ⑨ 검수 ─▶ ⑩ 연재
   (기획안)     (시놉시스·    (캐릭터    (화풍     │     (대본)       (컷 구성)  (컷 그림)  (대사·효과음)  (자동+대표)   (예약 공개)
                 시즌 플롯)    시트)     카드)     │
                                                 └─ 회차마다 반복
   ✋ 승인      ✋ 승인       ✋ 승인    ✋ 승인         ✋ 승인        ✋ 승인     (컷별 자동)   (자동)       ✋ 최종 승인
```

- ✋ 표시는 **승인 게이트**예요. 대표가 승인해야 다음 단계가 시작돼요.
- 작화와 말풍선은 컷이 많아서 컷마다 자동 검사로 통과시키고, 대표는 ⑨ 검수에서 한꺼번에 봐요. 대표가 원하면 작품 설정에서 "컷마다 승인"으로 바꿀 수 있어요.
- 처음 몇 작품은 모든 게이트를 켜고, 품질이 안정되면 ⑤ 회차 플롯을 자동 승인으로 바꾸는 식으로 줄여요.

인물을 스토리 뒤에 두는 이유: 스토리가 인물에게 필요한 결핍과 역할을 정해 주기 때문이에요. 단, ③ 인물을 고치면 ② 스토리의 일부(인물 이름, 관계)가 다시 맞춰져야 하므로 **양방향 점검**을 해요 (4절).

## 2. 단계별 상세

각 단계는 **입력, 사용하는 지침, 에이전트, 출력, 자동 검사, 대표가 할 수 있는 일**로 정의돼요.

### ① 장르·소재 (기획 에이전트)

| 항목 | 내용 |
| --- | --- |
| 입력 | 대표가 고른 장르, 소재 라이브러리 항목 1개 이상, 원하는 톤·연령 등급·대상 독자, 자유 메모 |
| 지침 | 02번 R-1~R-6, 장르 지침 |
| 출력 | 기획안 3개: 제목, 로그라인, 뿌리 연결 방식(R-3의 세 방법 중 무엇인지), 세계 규칙 3~5개, 시즌 1 줄거리, 겹침 점검 결과 |
| 자동 검사 | 뿌리가 엔진인지(R-2) 자가 평가, 기존 작품 겹침 점검 |
| 대표 | 하나 고르기, 섞기("A안 설정에 C안 주인공"), 직접 수정, 다시 생성 |

### ② 스토리 (스토리 에이전트)

| 항목 | 내용 |
| --- | --- |
| 입력 | 확정된 기획안 |
| 지침 | 02번 3장 (S-1~S-9), 장르 지침 |
| 출력 | 시놉시스, 시즌 아크(10화 단위 큰 사건), 회차별 한 줄 요약 30~50개, 떡밥 장부 초안, 절단 유형 배치표 |
| 자동 검사 | 첫 3화 법칙(S-5), 고구마 연속 2화 이하(S-6), 절단 유형 3연속 금지(S-2), 떡밥 회수 계획 유무 |
| 대표 | 회차 순서 바꾸기, 특정 회차만 다시 생성, 직접 수정 |

### ③ 주인공 및 등장인물 (캐릭터 에이전트 + 작화 에이전트)

| 항목 | 내용 |
| --- | --- |
| 입력 | 시놉시스, 시즌 아크 |
| 지침 | 02번 4장 (C-1~C-6), 04번 캐릭터 일관성 |
| 출력 | 인물별 설정(결핍, 원하는 것, 말투, 호칭 관계표, 시대에 맞는 이름), 외모 명세, **캐릭터 시트 이미지**(정면·측면·뒷모습, 표정 6종, 고정 의상) |
| 자동 검사 | 말투 구분 시험(C-2), 시트끼리 얼굴이 너무 닮지 않았는지 얼굴 유사도 검사 |
| 대표 | 시트 다시 그리기, 의상만 바꾸기, 이름·성격 수정 |

캐릭터 시트는 ④ 화풍이 정해진 뒤 **그 화풍으로 다시 그려요** (1화 시험에서 시트가 자기 화풍을 강요한 문제의 해결책).

### ④ 화풍 (작화 디렉터 에이전트)

| 항목 | 내용 |
| --- | --- |
| 입력 | 기획안의 톤, 장르, 뿌리의 시각 요소 |
| 지침 | 04번 1~2장 |
| 출력 | 화풍 후보 3개, 각각 화풍 카드(선, 채색, 명암, 팔레트, 배경 처리, 금지 요소)와 같은 장면 시험 컷 3장 |
| 대표 | 하나 고르기, 팔레트 조정. 확정되면 캐릭터 시트를 이 화풍으로 다시 그리고, 필요하면 작품 전용 LoRA를 학습해요 |

### ⑤ 회차 플롯 (스토리 에이전트)

| 항목 | 내용 |
| --- | --- |
| 입력 | 설정집(기획+인물+세계 규칙), 이전 회차 요약, 떡밥 장부, 이번 회차 한 줄 요약 |
| 지침 | 02번 S-1~S-4, D-1~D-7 |
| 출력 | **전개 설계표**(훅, 박자, 절단 유형, 이번에 심고 회수할 떡밥), 장면별 대본(대사·내레이션 포함) |
| 자동 검사 | 대사 금지 표현(D-5, D-6), 말풍선 길이(D-3), 설정 모순(세계 규칙, 이전 회차 사실) |
| 대표 | 대사 직접 수정, 장면 추가·삭제, 다시 생성 |

### ⑥ 콘티 (콘티 에이전트)

| 항목 | 내용 |
| --- | --- |
| 입력 | 확정 대본 |
| 지침 | 02번 S-10~S-16 |
| 출력 | 콘티 2~3안. 컷마다 샷 크기, 카메라 각도, 컷 세로 길이, 여백 길이, 등장인물과 위치, 표정, 조명, 대사 배치, 효과음, 그림 지시문 |
| 자동 검사 | 컷 수(S-16), 같은 샷 3연속 금지(S-12), 무대사 컷 수(S-13), 스크롤 리빌 유무(S-14) |
| 대표 | 안 고르기, 컷 순서 바꾸기, 컷 합치기·나누기 |

### ⑦ 작화 제작 (작화 에이전트 + 이미지 모델)

| 항목 | 내용 |
| --- | --- |
| 입력 | 확정 콘티의 컷, 화풍 카드, 캐릭터 시트, 작품 LoRA |
| 지침 | 04번 전체 |
| 처리 | 컷마다: 프롬프트 조립 → 생성(후보 2~4장) → 자동 결함 검사 → 최고점 선택 → 후처리(선 정리, 팔레트 맞춤, 질감) |
| 자동 검사 | 04번 5장의 결함 검사와 품질 점수. 기준 미달이면 결함을 고치도록 지시문을 바꿔 최대 3번 재생성, 그래도 미달이면 "대표 확인 필요"로 표시 |
| 대표 | 컷 다시 그리기, 일부만 고치기(인페인팅), 후보 중 다른 것 고르기 |

### ⑧ 말풍선 합성 (레터링 에이전트)

| 항목 | 내용 |
| --- | --- |
| 입력 | 완성 컷, 대사, 효과음 |
| 처리 | 말풍선 위치·크기·꼬리 방향 결정(얼굴과 손을 가리지 않게), 인물별 말풍선 모양(속마음은 점선, 정령은 떨리는 테두리 등), 효과음 손글씨 배치 |
| 저장 | 글자는 그림에 굽지 않고 레이어 데이터로 저장. 언어별로 같은 위치를 쓰되 길이에 맞춰 크기 자동 조정 |
| 자동 검사 | 글자가 컷 밖으로 나가는지, 얼굴을 가리는지, 읽는 순서가 맞는지(위→아래, 좌→우) |

### ⑨ 검수 (검수 에이전트 + 대표)

| 항목 | 내용 |
| --- | --- |
| 자동 | 고정 채점표로 회차 점수(04번 6장). 채점표는 회차마다 바뀌지 않고, 수정은 **최대 2라운드** (1화 시험에서 점수가 79→81→79로 수렴하지 않았던 문제의 해결책) |
| 대표 | 실제 독자 화면 그대로 미리보기, 컷별 코멘트, 승인 또는 반려(반려 시 어느 단계로 돌려보낼지 선택) |
| 기록 | 대표의 선택·수정·승인은 모두 제작 원장에 남겨요 (저작권 기여 증거) |

### ⑩ 연재

공개 일시 예약, 회차 상태(선공개 → 유료 → 기다무 → 무료) 전환 일정 자동 설정, 공개 시 관심 등록 독자에게 알림.

## 3. 승인 게이트의 동작

- 각 단계 결과에는 상태가 있어요: `생성 중` → `검토 대기` → `승인` / `반려` / `수정됨`
- 대표가 결과를 직접 고치면 `수정됨`으로 표시되고, 고친 내용(전후 비교)을 원장에 남겨요
- 승인되면 다음 단계 작업이 큐에 자동으로 들어가요
- 대기 중인 승인은 관리자 대시보드와 휴대폰 알림으로 보여줘요

## 4. 앞 단계를 고치면: 다시 생성 규칙

모든 결과물은 **어떤 입력으로 만들어졌는지(입력 지문)** 를 저장해요. 앞 단계가 바뀌면 그 결과를 입력으로 쓴 뒤 단계들이 "낡음"으로 표시돼요. 무조건 다 다시 만들지는 않고, 대표가 범위를 골라요.

| 바뀐 것 | 영향 받는 것 | 기본 동작 |
| --- | --- | --- |
| 세계 규칙, 기획안 | 스토리, 이후 전부 | 낡음 표시만. 대표가 "스토리부터 다시"를 눌러야 진행 |
| 인물 설정 (성격·말투) | 회차 대본의 해당 인물 대사 | 해당 인물이 나오는 회차만 낡음 표시 |
| 인물 외모·시트 | 그 인물이 나오는 컷 | 해당 컷만 다시 그리기 제안 (비용 미리 표시) |
| 화풍 카드 | 모든 컷 | 낡음 표시만. 이미 공개한 회차는 건드리지 않음 |
| 대본 대사만 | 말풍선 | 그림은 그대로, 말풍선만 자동 갱신 |
| 대본 장면 구성 | 콘티, 작화, 말풍선 | 바뀐 장면의 컷만 다시 |
| 콘티 한 컷 | 그 컷의 작화, 말풍선 | 그 컷만 자동 재생성 |

양방향 점검: ③ 인물에서 이름이나 관계를 바꾸면 ② 스토리 문서에서 해당 부분을 찾아 고친 안을 보여주고 대표가 승인해요.

**비용 보호:** 다시 생성 전에 예상 비용(컷 수 × 단가)을 보여주고, 월 예산을 넘으면 멈춰요.

## 5. 지침과 프롬프트 관리

관리자 스튜디오의 "지침 관리"에서 대표가 모든 에이전트의 지시를 고칠 수 있어요.

- **계층:** 전체 지침 < 장르 지침 < 작품 지침 < 회차 메모. 아래 계층이 위를 덮어써요
- **구성:** 에이전트마다 `역할 설명`, `규칙 목록`(02·04번의 번호 규칙), `금지 목록`, `출력 형식`, `예시`
- **버전:** 저장할 때마다 새 버전. 모든 결과물에 어느 지침 버전으로 만들었는지 기록. 이전 버전으로 되돌리기 가능
- **시험 실행:** 지침을 바꾼 뒤 저장 전에 "이 지침으로 3컷만 시험"을 돌려 비교
- **모델 선택:** 단계별로 쓸 LLM과 이미지 모델, 온도, 후보 수를 설정

## 6. 에이전트 목록

| 에이전트 | 모델(초기안) | 하는 일 |
| --- | --- | --- |
| 기획 | Claude (상위 모델) | 기획안, 겹침 점검 |
| 스토리 | Claude (상위 모델) | 시놉시스, 시즌 아크, 회차 대본 |
| 캐릭터 | Claude | 인물 설정, 말투, 이름 |
| 작화 디렉터 | Claude (이미지 이해) | 화풍 카드, 컷별 그림 지시문 조립 |
| 콘티 | Claude | 컷 구성 |
| 작화 | 이미지 모델 (아래) | 컷 생성, 부분 수정 |
| 레터링 | Claude (이미지 이해) + 렌더러 | 말풍선·효과음 배치 |
| 영어 대사 | Claude | 영어판 대사 재작성과 직역 점검 |
| 검수 | Claude (이미지 이해) + 검사 도구 | 결함 검사, 채점, 수정 지시 |

이미지 모델은 04번 4장에서 컷 종류별로 정해요. 1화 시험에서 쓴 모델은 nano-banana(참조 이미지 편집), 비교한 모델은 flux-dev, flux-ultra, seedream4예요.
