## 세 가지 원칙

1. **뿌리는 한국.** 모든 작품은 한국의 역사, 설화, 민속에서 최소 하나의 뿌리를 가져와요. 뿌리 없는 작품은 기획 단계를 통과하지 못해요.
2. **전개는 K-문법.** 한국 드라마·영화·웹툰이 독자를 붙잡는 방식(절단신공, 사이다와 고구마, 떡밥 회수, 세로 스크롤 호흡)을 지침으로 강제해요.
3. **AI처럼 보이면 실패.** 그림과 대사 모두 "AI스러움"을 결함으로 보고, 자동 검사와 사람 검수를 거쳐야 연재돼요.

## 이전 작업과의 관계

- 제작 파이프라인 시제품은 `claude/project-thread-8mf8zv` 브랜치의 `production/`에 있어요 (plan, decide, produce, letter 명령). 이 문서의 파이프라인은 그 시제품을 관리자 페이지에서 단계별로 돌릴 수 있게 넓힌 설계예요.
- 1화 시험 제작(Salt & Incense)에서 나온 문제(AI 같은 그림, 일본식 도리이, 가짜 글자, 품질검수 점수가 수렴하지 않음, 어색한 번역)는 04번 지침과 03번 검수 단계에 해결책으로 반영했어요.
